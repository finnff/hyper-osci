```
│   GND ──────┼────▶│                                         │

                    │  GPIO1 (Sigma-Delta DAC) ──────────────┼──▶ Scope X
                    │                                         │    (direct audio)
                    │  GPIO3 ─────┬─────[R1 1k]──┬──[Pot]───┼──▶ Scope Y
                    │             │              │           │    (low-pass ~159Hz)
                    │             └──[C1 1µF]────┴── GND     │
                    │                                         │
                    │  5V USB ◀── LiPo + TP4056              │
                    └─────────────────────────────────────────┘
```

**How it works:**
- Mic audio → ESP32 ADC → Sigma-Delta DAC → X channel (raw audio)
- Same signal → RC low-pass filter → Y channel (bass frequencies, phase shifted)
- Result: Lissajous patterns that react to audio

- 16-bit stereo
- ~$2 per module
- Much better quality than Sigma-Delta
- Simple I2S interface

- Better audio quality (16-bit vs 8-bit)
- ESP32-S3 has more RAM/CPU for processing
- Can do more complex local effects

**Cons:**
- New boards needed
- Slightly more complex

## Fallback Mode Implementation

### Firmware State Machine

```
                    ┌─────────────────┐
                    │   POWER ON      │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Try WiFi Connect│
                    │   (timeout 5s)  │
                    └────────┬────────┘
                             │
              ┌──────────────┴──────────────┐
              │                             │
              ▼                             ▼
     ┌─────────────────┐         ┌─────────────────┐
     │  WiFi Connected │         │  WiFi Failed    │
     │                 │         │                 │
     │  → NETWORK MODE │         │  → LOCAL MODE   │
     └────────┬────────┘         └────────┬────────┘
              │                           │
              ▼                           ▼
     ┌─────────────────┐         ┌─────────────────┐
     │ Receive PC audio│         │ Use local mic   │
     │ Mix with local  │         │ X = audio       │
     │ mic (optional)  │         │ Y = low-pass    │
     └────────┬────────┘         └─────────────────┘
              │
              │ If connection lost
              │ for > 1 second
              │
              └──────────────────▶ LOCAL MODE
```

### Seamless Transition

```cpp
// Pseudocode for graceful fallback
void audio_task() {
    while (true) {
        if (network_audio_available()) {
            // Network mode: use PC audio, optionally mix mic
            output = mix(network_audio, local_mic * mic_blend);
        } else {
            // Fallback mode: local mic only
            output.x = local_mic;
            output.y = low_pass_filter(local_mic);
        }
        
        dac_output(output);
    }
}
```

# HYPEROSCI v3.2 - Dual DAC Solutions

**Date:** 2026-02-02  
**Status:** Hardware Research

---

## Problem Statement

Current setup won't work for osci-render because:
1. **Scope X** = hardwired to MAX4466 (analog passthrough, no MCU control)
2. **Scope Y** = ESP32-C3 Sigma-Delta DAC (only 8-bit, poor quality)

**Need:** Both X and Y channels controlled by MCU with decent DAC resolution (12-16 bit)

---

## Dual DAC Options Comparison

### Option 1: PCM5102A (I2S Stereo DAC) ⭐ RECOMMENDED

```
ESP32 ──I2S──▶ PCM5102A ──▶ L (Scope X)
                        ──▶ R (Scope Y)
```

| Spec | Value |
|------|-------|
| Resolution | 32-bit (24-bit effective) |
| Sample Rate | Up to 384kHz |
| Interface | I2S |
| Channels | 2 (stereo) |
| Output | Line-level analog |
| Price | ~€1.50-2.00 module |
| Availability | Extremely common |

**Pros:**
- Excellent audio quality
- Simple I2S interface (3 wires: BCK, LRCK, DIN)
- Cheap modules widely available
- Built-in output filtering
- Works great with ESP32-S3

**Cons:**
- Requires I2S (not available on all MCUs)
- Module needs 3.3V and 5V

**Module pinout (typical):**
```
┌─────────────────────────────┐
│       PCM5102A Module       │
├─────────────────────────────┤
│ VCC  ── 3.3V                │
│ GND  ── Ground              │
│ BCK  ── I2S Bit Clock       │
│ LCK  ── I2S L/R Clock       │
│ DIN  ── I2S Data In         │
│ SCK  ── System Clock (GND*) │
│ LOUT ── Left output (X)     │
│ ROUT ── Right output (Y)    │
│ GND  ── Ground              │
└─────────────────────────────┘
* SCK to GND = internal clock generation
```

### Option 2: MCP4822 (SPI Dual DAC)

```
ESP32 ──SPI──▶ MCP4822 ──▶ VOUTA (Scope X)
                       ──▶ VOUTB (Scope Y)
```

| Spec | Value |
|------|-------|
| Resolution | 12-bit |
| Sample Rate | ~100kHz max practical |
| Interface | SPI |
| Channels | 2 |
| Output | 0-2.048V or 0-4.096V |
| Price | ~€2-3 |

**Pros:**
- SPI works with any MCU
- No external clock needed
- Good for lower sample rates

**Cons:**
- Only 12-bit (vs 24-bit PCM5102)
- SPI overhead limits sample rate
- Output voltage may need amplification

---

### Option 3: MCP4728 (I2C Quad DAC)

```
ESP32 ──I2C──▶ MCP4728 ──▶ VOUTA (Scope X)
                       ──▶ VOUTB (Scope Y)
                       ──▶ VOUTC (spare)
                       ──▶ VOUTD (spare)
```

| Spec | Value |
|------|-------|
| Resolution | 12-bit |
| Sample Rate | ~50kHz max (I2C limited) |
| Interface | I2C |
| Channels | 4 |
| Output | 0-VCC (internal ref: 2.048V) |
| Price | ~€3-4 |

**Pros:**
- I2C = only 2 wires
- 4 channels (future expansion)
- Has EEPROM (saves settings)

**Cons:**
- I2C too slow for high sample rates
- Only 12-bit

---

### Option 4: PT8211 (I2S Stereo DAC - Budget)

```
ESP32 ──I2S──▶ PT8211 ──▶ L (Scope X)
                      ──▶ R (Scope Y)
```

| Spec | Value |
|------|-------|
| Resolution | 16-bit |
| Sample Rate | Up to 96kHz |
| Interface | I2S |
| Channels | 2 |
| Output | ~1.2Vpp |
| Price | ~€0.50-1.00 |

**Pros:**
- Cheapest option
- Simple I2S
- 16-bit is good enough

**Cons:**
- No module readily available (bare chip)
- Lower output voltage (needs amplification)
- Needs external filtering

---

### Option 5: ESP32-S3 + External DAC vs STM32 Built-in

**ESP32-S3 + PCM5102A:**
- ESP32-S3 has I2S peripheral
- External DAC provides excellent quality
- WiFi built-in

**STM32F446 (Built-in DAC):**
- Has 2× 12-bit DAC built-in
- No external parts needed
- BUT: No WiFi (needs separate ESP32 for network)

**Recommendation:** ESP32-S3 + PCM5102A is simpler overall (one chip does WiFi + I2S)

### Firmware Modes

```cpp
enum class Mode {
    LOCAL_MIC,      // Fallback: mic audio → X, low-pass → Y
    NETWORK_OSCI,   // osci-render from PC → X,Y
    NETWORK_MIX     // osci-render + mic mixed
};

void audio_loop() {
    int16_t left, right;
    
    switch (current_mode) {
        case Mode::LOCAL_MIC:
            // Read mic, generate X/Y locally
            float mic = adc_read(MIC_PIN);
            left = mic * 32767;                    // X = raw audio
            right = low_pass_filter(mic) * 32767;  // Y = bass
            break;
            
        case Mode::NETWORK_OSCI:
            // Use network audio directly
            if (network_buffer.available()) {
                left = network_buffer.read_left();
                right = network_buffer.read_right();
            }
            break;
            
        case Mode::NETWORK_MIX:
            // Mix network with local mic
            float mic = adc_read(MIC_PIN);
            left = network_buffer.read_left() + mic * mic_mix_level;
            right = network_buffer.read_right() + mic * mic_mix_level;
            break;
    }
    
    i2s_write_stereo(left, right);
}
```

## PCM5102A Module Wiring

### ESP32-S3 to PCM5102A

| ESP32-S3 Pin | PCM5102A Pin | Function |
|--------------|--------------|----------|
| GPIO 4 | BCK | Bit Clock |
| GPIO 5 | LCK | L/R Clock (Word Select) |
| GPIO 6 | DIN | Data In |
| 3V3 | VCC | Power |
| GND | GND | Ground |
| - | SCK | Tie to GND (internal clock) |

### PCM5102A to Oscilloscope

| PCM5102A | Scope | Notes |
|----------|-------|-------|
| LOUT | CH1 (X) | Left channel |
| ROUT | CH2 (Y) | Right channel |
| GND | Scope GND | Common ground |

**Output level:** ~2Vpp at full scale (good for scope)

## Sample Code: ESP32-S3 + PCM5102A

```cpp
#include <driver/i2s.h>

#define I2S_BCK_PIN  4
#define I2S_WS_PIN   5
#define I2S_DOUT_PIN 6
#define SAMPLE_RATE  48000

void i2s_init() {
    i2s_config_t i2s_config = {
        .mode = (i2s_mode_t)(I2S_MODE_MASTER | I2S_MODE_TX),
        .sample_rate = SAMPLE_RATE,
        .bits_per_sample = I2S_BITS_PER_SAMPLE_16BIT,
        .channel_format = I2S_CHANNEL_FMT_RIGHT_LEFT,
        .communication_format = I2S_COMM_FORMAT_STAND_I2S,
        .intr_alloc_flags = ESP_INTR_FLAG_LEVEL1,
        .dma_buf_count = 8,
        .dma_buf_len = 256,
        .use_apll = true,  // Better clock accuracy
        .tx_desc_auto_clear = true
    };
    
    i2s_pin_config_t pin_config = {
        .bck_io_num = I2S_BCK_PIN,
        .ws_io_num = I2S_WS_PIN,
        .data_out_num = I2S_DOUT_PIN,
        .data_in_num = I2S_PIN_NO_CHANGE
    };
    
    i2s_driver_install(I2S_NUM_0, &i2s_config, 0, NULL);
    i2s_set_pin(I2S_NUM_0, &pin_config);
}

void output_sample(int16_t left, int16_t right) {
    uint32_t sample = ((uint32_t)right << 16) | (uint16_t)left;
    size_t bytes_written;
    i2s_write(I2S_NUM_0, &sample, sizeof(sample), &bytes_written, portMAX_DELAY);
}

// Generate circle (test pattern)
void generate_circle(float freq) {
    static float phase = 0;
    float x = cosf(phase) * 32767;
    float y = sinf(phase) * 32767;
    output_sample((int16_t)x, (int16_t)y);
    phase += 2.0f * M_PI * freq / SAMPLE_RATE;
    if (phase > 2.0f * M_PI) phase -= 2.0f * M_PI;
}
```

## Fallback Mode Implementation

Even with new hardware, we keep fallback mode:

```cpp
// Check WiFi status periodically
void check_connection() {
    static uint32_t last_packet = 0;
    
    if (millis() - last_packet > 1000) {
        // No packets for 1 second = fallback
        current_mode = Mode::LOCAL_MIC;
    }
}

// Local mic processing (fallback)
void process_local_mic() {
    // Read ADC
    float mic = (float)analogRead(MIC_PIN) / 4095.0f - 0.5f;
    
    // Simple low-pass filter for Y channel
    static float y_filtered = 0;
    float alpha = 0.1f;  // Cutoff ~160Hz at 48kHz
    y_filtered = alpha * mic + (1.0f - alpha) * y_filtered;
    
    // Output
    int16_t x = mic * 32767;
    int16_t y = y_filtered * 32767;
    output_sample(x, y);
}
```
